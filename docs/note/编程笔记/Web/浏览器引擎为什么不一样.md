# 浏览器引擎为什么不一样

> 同一句"隐藏滚动条"，Firefox 和 Chrome/Edge/Safari 要写两行不同的 CSS 才能都生效。原因要追溯到浏览器圈一段"各说各话"的历史。

## 一句话答案

**浏览器是不同公司做的，每家的"内核引擎"不一样。** 滚动条样式在很长时间里没有统一标准，各引擎就各自发明了私有的写法；后来 W3C 补了统一标准，但老写法已经满地都是， 于是"普通话"和"方言"长期并存。

## 三家浏览器，三种引擎

每个浏览器渲染页面的核心程序叫"引擎"，可以理解成方言：

| 浏览器 | 引擎 | 谁做的 |
|---|---|---|
| Chrome | Blink | Google |
| Edge | Blink | 微软（2020 年放弃自研，改用 Chrome 同款引擎） |
| Safari | WebKit | 苹果 |
| Firefox | Gecko | Mozilla |

注意：Chrome 的 Blink 其实是从 Safari 家的 WebKit **分家**出来的——所以 Chrome、Edge、Safari 三家说的是同一门方言。

## 时间线：先有方言，后有普通话

- **约 2009 年**：Safari 想自定义滚动条，等不及有标准，自己发明了 `::-webkit-scrollbar`。前缀 `-webkit-` 就是引擎的名字，意思是"这是 WebKit 引擎的私货"。Chrome 后来照抄了这套写法，Edge 换引擎后同样能用——所以**一行 `-webkit-` 就管住了三家**。
- **Firefox（Mozilla）的态度**：坚持"非标准的东西我不实现"，不认 `::-webkit-scrollbar`。这就是 MDN 把它标注为"非标准"的原因。
- **2018 年**：W3C（定 Web 标准的组织）终于补上正式标准，规定了 `scrollbar-width` 和 `scrollbar-color` 两个标准属性。Firefox 2018 年第一个支持。
- **2024 年**：Chrome（年初）和 Safari（年底）才陆续跟进标准写法，MDN 显示"Baseline 2024 年 12 月"，说的就是这件事。

## 所以滚动条那两行代码是

```css
scrollbar-width: none;                       /* 新普通话：Firefox 认，三家 2024 年后也认 */
html::-webkit-scrollbar { display: none; }   /* 老方言：Chrome/Edge/Safari 从小用到大 */
```

两行都写，就同时照顾了"讲方言的老浏览器"和"讲普通话的新浏览器"。再过几年等旧版 Chrome 淘汰干净，第一行就够了，第二行到时候可以删——但现阶段留着更稳妥。

具体每个属性的含义和官方文档，见[浏览器滚动条隐藏](浏览器滚动条隐藏.md)。

## 附：厂商前缀小知识

这种"引擎名当前缀"的写法叫**厂商前缀**（vendor prefix），历史上还有几个：

| 前缀 | 引擎 | 对应浏览器 |
|---|---|---|
| `-webkit-` | WebKit / Blink | Chrome、Edge、Safari |
| `-moz-` | Gecko | Firefox |
| `-ms-` | Trident | 老版 IE |
| `-o-` | Presto | 老 Opera |

以后在别人的 CSS 里看到这些前缀，就知道那是引擎私有写法，对应哪个浏览器。
