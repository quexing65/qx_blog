# 浏览器滚动条是怎么隐藏的

> 本博客全站都看不到浏览器自带的右侧滚动条，但滚动完全正常。这篇记下实现原理、每行代码的含义，以及去哪里查官方文档。

## 本博客的做法：隐藏原生的，自己画一个

整体思路分两层：

1. **CSS 隐藏原生滚动条** —— 只是"看不见"，滚轮、触摸、键盘滚动完全不受影响
2. **JS 自绘一个进度小滑块** —— 滚动时淡入，停止滚动 1.2 秒后自动淡出

相关代码在仓库里的位置：

| 文件 | 作用 |
|---|---|
| `docs/css/toc.css` | 全站隐藏原生滚动条；目录、手机面板自身的滚动条也一并隐藏 |
| `docs/css/theme.css` | 设计决策注释：为什么选"隐藏"而不是"美化" |
| `docs/js/reading-progress.js` | 自绘右侧小滑块 + 顶部常驻进度横条 |

## 第一步：两条 CSS 规则覆盖所有浏览器

```css
/* docs/css/toc.css */
html {
  scrollbar-width: none;        /* 标准写法，Firefox 认 */
}
html::-webkit-scrollbar {
  display: none;                /* 老写法，Chrome / Edge / Safari 认 */
}
```

为什么要写两条？因为两个属性出身不同：

| 写法 | 性质 | 谁认 |
|---|---|---|
| `scrollbar-width: none` | W3C 正式标准 | Firefox；Chrome/Safari 2024 年底起也认 |
| `::-webkit-scrollbar { display: none }` | 非标准（WebKit 引擎私货） | Chrome、Edge、Safari 从始至终只认它 |

`scrollbar-width` 有三个取值：

- `auto` —— 系统默认宽度（初始值）
- `thin` —— 更细的滚动条
- `none` —— **不显示滚动条，但元素依然可以滚动** ← 博客用的就是这个

## 为什么是"隐藏"而不是"美化"

`docs/css/theme.css` 里有一条设计决策注释：项目**故意不自定义** `::-webkit-scrollbar` 的颜色。因为一旦自定义了颜色，Chrome/Edge 会放弃原生 overlay 滚动条行为（悬浮在内容上、不用时自动隐藏的样式），导致亮色/暗色模式观感不一致。所以与其"美化"，不如整条隐藏、再用 JS 画个自己的。

## 第二步：自己画一个滑块（reading-progress.js）

原生滚动条隐藏后，右侧的视觉反馈由 `docs/js/reading-progress.js` 创建的 `.scroll-indicator` 承担，原理是监听 `scroll` 事件、用三个几何量模拟原生滚动条的逻辑：

- `scrollHeight` —— 整页内容的高度
- `clientHeight` —— 浏览器窗口可视区的高度
- `scrollTop` —— 已经滚过去多少

```
滑块高度 = clientHeight / scrollHeight × clientHeight
滑块位置 = 滚动进度比例 ×（可视区高度 − 滑块高度）
```

滚动时滑块以 opacity 0.5 淡入，**停止滚动 1.2 秒后淡出**——比原生滚动条更克制。同一个脚本还创建了顶部常驻的阅读进度横条（`.reading-progress`）。

另外，局部滚动容器的滚动条也用同样方式隐藏了：桌面目录列表 `.page-toc-list`、手机底部面板 `.toc-sheet-list`（目录的原生滚动条太窄太抢眼）。目录列表还配了 `overscroll-behavior: contain`，滚到目录尽头不会连带页面一起滚。

## 官方文档在哪查

权威出处叫 **MDN**（Mozilla Developer Network，有中文版），是 Web 开发公认的"官方字典"：

- [MDN - scrollbar-width](https://developer.mozilla.org/zh-CN/docs/Web/CSS/scrollbar-width)
- [MDN - ::-webkit-scrollbar](https://developer.mozilla.org/zh-CN/docs/Web/CSS/::-webkit-scrollbar)
- [W3C 规范原文 - CSS Scrollbars Styling Module Level 1](https://www.w3.org/TR/css-scrollbars-1/)（偏学术，日常查 MDN 就够）

**学习方法**：以后遇到看不懂的 CSS，直接搜"**MDN + 属性名**"（比如 `MDN scrollbar-width`），第一个结果就是。每个 MDN 属性页固定有几块内容：

1. 语法和取值
2. 可以直接改着玩的示例
3. **浏览器兼容表** —— 能看出"哪个浏览器要用哪种写法"，正是本博客写两行代码的原因
4. 相关属性链接（顺着点能扩展学习）

⚠️ 无障碍小提醒（MDN 文档里也写了）：隐藏滚动条要确保用户仍有别的滚动方式。本博客滚轮、触摸、自绘滑块都在，所以没问题。
