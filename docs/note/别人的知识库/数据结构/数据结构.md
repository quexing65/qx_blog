# 并查集（Disjoint Set Union）

> 并查集用于维护一组互不相交的集合，擅长回答“两个元素是否连通”以及“把两个集合合并”这类问题。

## 1. 适用场景

- 无向图连通性：判断两个节点是否属于同一连通分量。
- 动态合并：不断加入连接关系，并随时查询连通状态。
- 检测环：加入一条边前，若两个端点已经连通，则该边会形成环。
- Kruskal 最小生成树：按边权从小到大选择不会形成环的边。
- 等价关系分组：账户合并、朋友圈、同类项聚合等。

并查集适合“只合并、不拆分”的动态集合。如果需要频繁删除边或拆分集合，应考虑其他数据结构。

## 2. 三个核心操作

| 操作 | 作用 |
|---|---|
| `find(x)` | 查找元素 `x` 所在集合的代表元（根节点） |
| `union(a, b)` | 合并 `a` 和 `b` 所在的集合 |
| `connected(a, b)` | 判断 `a` 和 `b` 是否属于同一集合 |

最初每个元素各自形成一个集合，即 `parent[x] = x`。

## 3. 两个关键优化

### 3.1 路径压缩

调用 `find(x)` 时，让查找路径上的节点直接指向根节点。后续查询会更快。

### 3.2 按集合大小合并

合并时把较小的树挂到较大的树下，避免树退化成很长的链。也可以记录秩（`rank`）并按秩合并，两种方案选择一种即可。

同时使用路径压缩和按大小合并后，单次操作的均摊复杂度为 `O(α(n))`。其中 `α` 是反阿克曼函数，在实际数据规模下可以近似看作常数。

## 4. Python 实现

```python
class DisjointSetUnion:
    def __init__(self, size: int) -> None:
        if size < 0:
            raise ValueError("size 不能为负数")

        self.parent = list(range(size))
        self.component_size = [1] * size
        self.component_count = size

    def find(self, node: int) -> int:
        """返回 node 所在集合的代表元，并执行路径压缩。"""
        if not 0 <= node < len(self.parent):
            raise IndexError("节点编号超出范围")

        root = node
        while root != self.parent[root]:
            root = self.parent[root]

        while node != root:
            next_node = self.parent[node]
            self.parent[node] = root
            node = next_node

        return root

    def union(self, left: int, right: int) -> bool:
        """合并两个集合；发生合并时返回 True，原本已连通时返回 False。"""
        left_root = self.find(left)
        right_root = self.find(right)

        if left_root == right_root:
            return False

        if self.component_size[left_root] < self.component_size[right_root]:
            left_root, right_root = right_root, left_root

        self.parent[right_root] = left_root
        self.component_size[left_root] += self.component_size[right_root]
        self.component_count -= 1
        return True

    def connected(self, left: int, right: int) -> bool:
        return self.find(left) == self.find(right)

    def size_of(self, node: int) -> int:
        return self.component_size[self.find(node)]
```

## 5. 使用示例

```python
dsu = DisjointSetUnion(6)

dsu.union(0, 1)
dsu.union(1, 2)
dsu.union(3, 4)

print(dsu.connected(0, 2))  # True
print(dsu.connected(0, 4))  # False
print(dsu.size_of(1))       # 3
print(dsu.component_count)  # 3：{0,1,2}、{3,4}、{5}
```

### 检测无向图中的环

```python
def has_cycle(node_count: int, edges: list[tuple[int, int]]) -> bool:
    dsu = DisjointSetUnion(node_count)

    for left, right in edges:
        if not dsu.union(left, right):
            return True

    return False
```

## 6. 常见误区

- 不要直接比较 `parent[a] == parent[b]`，父节点未必已经是根节点，应调用 `find()`。
- `union()` 前必须先查找两边的根节点，不能直接修改原节点的父指针。
- 按大小合并时，集合大小只记录在根节点上。
- 并查集默认处理的是固定编号范围；字符串或其他对象可先映射为整数，或用字典存储父节点。
- 普通并查集不能高效处理删除连接、集合拆分或最短路径问题。
