## 学习建议

1. 先完成基础篇的表结构、CRUD、查询、约束与事务练习。
2. 再用进阶篇理解索引与执行计划，并把优化结论放到真实数据上验证。
3. 最后在隔离的实验环境学习复制、分片和读写分离；生产配置必须额外完成安全、备份、恢复和故障演练。

## 知识体系

```text
MySQL
├── 基础
│   ├── 数据库与环境：安装、服务、客户端连接
│   ├── SQL：DDL、DML、DQL、DCL 与常用函数
│   ├── 数据完整性：约束、外键与多表关系
│   └── 事务：ACID、并发问题与隔离级别
├── 进阶
│   ├── 存储引擎：InnoDB、MyISAM、Memory
│   ├── 索引与优化：B+Tree、执行计划、索引设计、SQL 优化
│   ├── 数据库对象：视图、存储过程、函数与触发器
│   └── InnoDB：锁、redo/undo log、MVCC 与 ReadView
└── 运维
    ├── 日志：错误、二进制、查询与慢查询日志
    ├── 复制：一主一从与双主双从实验
    ├── 分片：垂直/水平拆分与 MyCat 分片规则
    └── 读写分离：拓扑、路由与验证
```
