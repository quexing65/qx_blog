# 08. 软件安装与系统服务

#### 8.使用 DNF / YUM 管理软件

* 包管理器说明

  * DNF/YUM 会从已配置的软件仓库解析依赖、安装、升级或卸载软件。现代 Fedora、RHEL 及多数兼容发行版以 `dnf` 为主；部分系统保留 `yum` 兼容命令.

* 格式

  ```sh
  dnf [install | search | remove | upgrade | info] 软件包名
  
  # 常用子命令:
  install        # 安装软件包
  search         # 搜索软件包（不会自动安装）
  remove         # 卸载软件包
  upgrade        # 升级已安装的软件包
  info           # 查看软件包信息
  -y             # 可选：自动确认；执行前仍应核对将发生的变更
  ```

* 实例

  ```sh
  # 安装 wget 命令, 可以联网下载资源
  sudo dnf install wget
  
  # wget命令的用法
  # 格式: wget url地址
  wget https://img.zjol.com.cn/mlf/dzw/zjczw/gun/202011/W020201118626559068829.jpeg
  ```



#### 9.systemctl-系统管理命令

```sh
# 格式
systemctl [start | stop | status | disable | enable | restart] 服务名

# 常用的服务
NetworkManager          # 常见的网络连接管理服务
firewalld               # 动态防火墙服务
sshd                    # OpenSSH 服务端

# 实例
 

# 网络异常时先诊断，不要直接停用 NetworkManager:
ip address
ip route
nmcli device status
nmcli connection show
systemctl status NetworkManager
journalctl -u NetworkManager --since today
```

`127.0.0.1` 是固定的 IPv4 回环地址，不表示网卡地址“变成了”它。应根据诊断结果检查虚拟机网卡模式、连接配置、DHCP、DNS 或防火墙。远程操作网络服务前要准备控制台或其他恢复通道，避免把自己断开。
