# 11. 压缩与解压缩

## tar 命令（tarball + gzip）

```bash
# 压缩
tar -zcvf 压缩包名.tar.gz 文件1 文件2 ...
# z:gzip协议  c:创建  v:显示过程  f:文件

# 解压
tar -zxvf 压缩包名.tar.gz [-C 目标路径]
# x:解压缩  -C:指定解压路径
```

## 示例

```bash
tar -zcvf my.tar.gz 1.txt 2.txt 3.txt      # 压缩
tar -zxvf my.tar.gz -C aa                   # 解压到 aa 目录
```
