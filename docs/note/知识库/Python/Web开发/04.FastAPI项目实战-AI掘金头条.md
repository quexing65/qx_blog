### 密码哈希

```python
from pwdlib import PasswordHash

password_hash = PasswordHash.recommended()  # 当前推荐配置使用 Argon2

def hash_password(password: str) -> str:
    return password_hash.hash(password)

def verify_password(plain_password: str, hashed_password: str) -> bool:
    return password_hash.verify(plain_password, hashed_password)
```

密码只能存储带随机盐的慢哈希，不能明文保存，也不是“可解密的加密”。已有 Passlib/Bcrypt 数据可在迁移期间继续验证，新系统可采用 `pwdlib[argon2]` 的推荐配置。

### Token 认证

```python
from hashlib import sha256
from typing import Annotated

from fastapi import Depends, HTTPException
from fastapi.security import HTTPAuthorizationCredentials, HTTPBearer

bearer_scheme = HTTPBearer()

async def get_current_user(
    credentials: Annotated[HTTPAuthorizationCredentials, Depends(bearer_scheme)],
    db: AsyncSession = Depends(get_db),
):
    token_hash = sha256(credentials.credentials.encode("utf-8")).hexdigest()
    user = await users.get_user_by_token_hash(db, token_hash)
    if not user:
        raise HTTPException(status_code=401, detail="无效的令牌或已经过期的令牌")
    return user
```

这里使用的是数据库保存的随机不透明令牌：令牌应由 `secrets.token_urlsafe()` 生成，只保存摘要，并在查询时同时校验 `expires_at`。如果改用 JWT，则必须验证签名、允许的算法、签发方、受众和过期时间。

## 5. Redis 缓存（Day06）

### 缓存键设计

```python
CATEGORIES_KEY = "news:categories"
NEWS_LIST_PREFIX = "news_list:"
NEWS_DETAIL_PREFIX = "news:detail:"
RELATED_NEWS_PREFIX = "news:related:"
```

### 缓存操作

```python
# 获取新闻分类缓存
async def get_cached_categories():
    return await get_json_cache(CATEGORIES_KEY)

# 写入新闻分类缓存
async def set_cache_categories(data: List[Dict[str, Any]], expire: int = 7200):
    return await set_cache(CATEGORIES_KEY, data, expire)

# 缓存新闻列表
async def set_cache_news_list(category_id: Optional[int], page: int, size: int, 
                              news_list: List[Dict[str, Any]], expire: int = 1800):
    category_part = category_id if category_id is not None else "all"
    key = f"{NEWS_LIST_PREFIX}{category_part}:{page}:{size}"
    return await set_cache(key, news_list, expire)

# 缓存新闻详情
async def cache_news_detail(news_id: int, news_data: Dict[str, Any], expire: int = 300):
    key = f"{NEWS_DETAIL_PREFIX}{news_id}"
    return await set_cache(key, news_data, expire)
```

**缓存策略：**
- 分类数据：7200秒（2小时）- 数据稳定
- 新闻列表：600秒（10分钟）- 更新频繁
- 新闻详情：300秒（5分钟）- 实时性要求高
- 验证码：120秒（2分钟）- 临时数据

## 7. 最佳实践

### 项目分层

```
├── models/      # 数据模型层（ORM）
├── schemas/     # 数据验证层（Pydantic）
├── crud/        # 数据访问层
├── routers/     # 路由层（API）
├── utils/       # 工具层
```

### 代码规范

1. **路由模块化**：使用 `APIRouter` 分组管理路由
2. **依赖注入**：数据库会话、认证信息通过依赖注入
3. **异步操作**：所有数据库操作使用 `async/await`
4. **错误处理**：统一异常处理，返回标准错误格式
5. **数据验证**：使用 Pydantic 模型验证请求和响应数据
