# 03. FastAPI 依赖注入与数据库

## 1. 中间件（Middleware）

### 1.1 什么是中间件

中间件是一个函数，它会在每个请求被特定的路径操作处理之前，以及在每个响应返回之前工作。

**中间件工作流程：**
```
请求 → 中间件1 → 中间件2 → ... → 路由处理 → ... → 中间件2 → 中间件1 → 响应
```

### 1.2 中间件基础用法

```python
from fastapi import FastAPI

app = FastAPI()

@app.middleware("http")
async def middleware1(request, call_next):
    print("中间件1 start")
    response = await call_next(request)
    print("中间件1 end")
    return response

@app.middleware("http")
async def middleware2(request, call_next):
    print("中间件2 start")
    response = await call_next(request)
    print("中间件2 end")
    return response

@app.get("/")
async def root():
    return {"message": "Hello World"}
```

**执行顺序：**
```
请求 → middleware1 start → middleware2 start → 路由处理 → middleware2 end → middleware1 end → 响应
```

### 1.3 实用示例：请求处理时间统计

```python
from fastapi import FastAPI, Request
import time

app = FastAPI()

@app.middleware("http")
async def add_process_time_header(request: Request, call_next):
    # 请求处理前执行
    start_time = time.time()

    # 调用下一个中间件或路由处理
    response = await call_next(request)

    # 请求处理后执行
    process_time = time.time() - start_time
    response.headers["X-Process-Time"] = str(process_time)

    return response

@app.get("/")
async def root():
    return {"message": "Hello World"}
```

### 1.4 中间件常见用途

| 用途 | 说明 |
|------|------|
| 请求日志 | 记录所有请求信息（URL、方法、IP、时间） |
| CORS 处理 | 跨域资源共享配置 |
| 身份验证 | 验证 Token 或 Session |
| 响应头添加 | 添加统一的响应头（如 X-Process-Time） |
| 性能监控 | 记录请求处理时间 |
| 错误处理 | 统一捕获和处理异常 |
| 请求限流 | 限制请求频率，防止滥用 |

### CORS 中间件

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000"],
    allow_credentials=True,
    allow_methods=["GET", "POST", "PUT", "PATCH", "DELETE"],
    allow_headers=["Authorization", "Content-Type"],
)
```

> 携带 Cookie 或 Authorization 等凭证时，应明确列出可信来源、方法和请求头。生产环境不要把 `allow_origins` 配成 `['*']`，来源列表应由环境配置提供。

## 2. 依赖注入（Dependency Injection）

### 2.1 什么是依赖注入

依赖注入是一种设计模式，允许你声明函数需要哪些依赖，然后由 FastAPI 自动提供这些依赖。

### 2.2 应用场景

| 场景 | 说明 |
|------|------|
| 数据库连接 | 获取数据库会话 |
| 身份验证 | 验证用户身份 |
| 权限检查 | 检查用户权限 |
| 参数校验 | 统一的参数校验逻辑 |
| 日志记录 | 统一的日志处理 |
| 缓存操作 | 获取缓存连接 |

### 2.3 基本用法

```python
from fastapi import FastAPI, Depends

app = FastAPI()

# 定义依赖函数
def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

# 在路由中使用依赖
@app.get("/items/")
def read_items(db = Depends(get_db)):
    items = db.query(Item).all()
    return items

# 多个依赖
@app.get("/users/{user_id}")
def read_user(
    user_id: int,
    db: Session = Depends(get_db),
    current_user = Depends(get_current_user)
):
    return {"user_id": user_id, "user": current_user}
```

### 2.4 带参数的依赖注入

```python
from fastapi import FastAPI, Query, Depends

app = FastAPI()

# 定义依赖项
async def common_parameters(
    skip: int = Query(0, ge=0),
    limit: int = Query(10, le=60)
):
    return {"skip": skip, "limit": limit}

# 使用 Depends 注入依赖项
@app.get("/news/news_list")
async def get_news_list(commons=Depends(common_parameters)):
    return commons

@app.get("/user/user_list")
async def get_user_list(commons=Depends(common_parameters)):
    return commons
```

**依赖注入的优势：**
- ✅ 代码复用：多个路由共享相同的参数逻辑
- ✅ 自动文档：依赖项的参数会自动出现在 API 文档中
- ✅ 层级支持：依赖项可以依赖其他依赖项
- ✅ 易于测试：可以轻松替换依赖项进行单元测试

## 3. SQLAlchemy ORM 基础

### 3.1 ORM 简介

ORM（Object-Relational Mapping，对象关系映射）是一种技术，它将数据库表映射为编程语言中的对象，使开发者可以使用面向对象的方式操作数据库，而不需要直接写 SQL 语句。

**常见 ORM 框架：**

| 框架 | 语言 | 特点 |
|------|------|------|
| SQLAlchemy | Python | 最流行的 Python ORM，功能强大 |
| Django ORM | Python | Django 自带 ORM，简单易用 |
| Peewee | Python | 轻量级 ORM，适合小项目 |

**ORM 使用流程：**
```
1. 安装依赖 → 2. 创建数据库引擎 → 3. 定义模型类 → 4. 创建表 → 5. CRUD 操作
```

**安装依赖：**
```bash
pip install sqlalchemy
pip install aiomysql  # MySQL 异步驱动
# 或
pip install psycopg2-binary  # PostgreSQL
```

### 3.2 异步引擎（推荐 - SQLAlchemy 2.0）

```python
from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker, AsyncSession

ASYNC_DATABASE_URL = "mysql+aiomysql://app_user:password@localhost:3306/fastapi_db?charset=utf8mb4"

async_engine = create_async_engine(
    ASYNC_DATABASE_URL,
    echo=True,           # 输出 SQL 日志
    pool_size=10,        # 连接池活跃连接数
    max_overflow=20      # 允许额外连接数
)
```

### 3.3 定义模型类

```python
from datetime import datetime
from sqlalchemy import DateTime, func, String, Float
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column

class Base(DeclarativeBase):
    create_time: Mapped[datetime] = mapped_column(
        DateTime, 
        insert_default=func.now(), 
        default=func.now, 
        comment="创建时间"
    )
    update_time: Mapped[datetime] = mapped_column(
        DateTime, 
        insert_default=func.now(), 
        default=func.now, 
        onupdate=func.now(), 
        comment="修改时间"
    )

class Book(Base):
    __tablename__ = "book"

    id: Mapped[int] = mapped_column(primary_key=True, comment="书籍id")
    bookname: Mapped[str] = mapped_column(String(255), comment="书名")
    author: Mapped[str] = mapped_column(String(255), comment="作者")
    price: Mapped[float] = mapped_column(Float, comment="价格")
    publisher: Mapped[str] = mapped_column(String(255), comment="出版社")
```

### 3.4 建表

```python
from contextlib import asynccontextmanager
from fastapi import FastAPI

async def create_tables() -> None:
    async with async_engine.begin() as conn:
        await conn.run_sync(Base.metadata.create_all)

@asynccontextmanager
async def lifespan(app: FastAPI):
    await create_tables()
    yield

app = FastAPI(lifespan=lifespan)
```

> `lifespan` 是当前推荐的启动与关闭资源管理方式。`create_all()` 适合教学和原型；生产环境应使用 Alembic 等迁移工具管理表结构，而不是每次启动时自动建表。

### 3.5 同步引擎

```python
from sqlalchemy import create_engine
from sqlalchemy.orm import DeclarativeBase, sessionmaker

# 数据库连接字符串
DATABASE_URL = "mysql+pymysql://root:password@localhost:3306/fastapi_db"

# 创建数据库引擎
engine = create_engine(DATABASE_URL)

# 创建会话工厂
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)

class Base(DeclarativeBase):
    pass

# 获取数据库会话的依赖
def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

**同步 vs 异步选择：**

| 场景 | 推荐方式 |
|------|----------|
| 调用链和数据库驱动都支持异步，且有大量并发 I/O | 异步会话 |
| 依赖同步库、任务量不大或团队更熟悉同步代码 | 同步会话 |
| 生产环境 | 两者都可；按依赖兼容性、复杂度与基准测试选择 |

---

### 3.6 创建会话工厂和依赖项（异步）

```python
AsyncSessionLocal = async_sessionmaker(
    bind=async_engine,
    class_=AsyncSession,
    expire_on_commit=False
)

async def get_database():
    async with AsyncSessionLocal() as session:
        try:
            yield session          # 返回数据库会话
            await session.commit() # 提交事务
        except Exception:
            await session.rollback()  # 异常回滚
            raise
```

`async with` 会负责关闭会话。是否在依赖中统一提交事务取决于项目的事务边界设计；复杂业务通常让服务层明确控制提交与回滚。

## 4. ORM 数据库操作

### 4.1 查询数据

```python
from sqlalchemy import select

# 查询所有
@app.get("/book/books")
async def get_book_list(db: AsyncSession = Depends(get_database)):
    result = await db.execute(select(Book))
    books = result.scalars().all()
    return books

# 查询单条（根据主键）
@app.get("/book/{book_id}")
async def get_book(book_id: int, db: AsyncSession = Depends(get_database)):
    book = await db.get(Book, book_id)
    return book

# 条件查询
@app.get("/book/search")
async def search_book(db: AsyncSession = Depends(get_database)):
    result = await db.execute(select(Book).where(Book.price >= 200))
    books = result.scalars().all()
    return books
```

### 4.2 模糊查询与逻辑运算

```python
from sqlalchemy import and_, or_, not_

# 模糊查询（like）- 区分大小写
result = await db.execute(select(Book).where(Book.author.like("曹%")))  # 以"曹"开头
result = await db.execute(select(Book).where(Book.author.like("%曹%")))  # 包含"曹"
result = await db.execute(select(Book).where(Book.author.like("%曹")))  # 以"曹"结尾

# ILIKE - 不区分大小写（仅 PostgreSQL）
# result = await db.execute(select(Book).where(Book.author.ilike("%cao%")))

# 逻辑运算符
# & 与（AND）
# | 或（OR）
# ~ 非（NOT）
result = await db.execute(
    select(Book).where(
        (Book.author.like("曹%")) | (Book.price > 100)
    )
)

# 使用 and_, or_, not_ 函数
result = await db.execute(
    select(Book).where(
        and_(Book.price > 100, Book.price < 1000)
    )
)

result = await db.execute(
    select(Book).where(
        or_(Book.author == "曹雪芹", Book.author == "鲁迅")
    )
)

# 包含查询（in_）
id_list = [1, 3, 5, 7]
result = await db.execute(select(Book).where(Book.id.in_(id_list)))

# 不包含（not in）
result = await db.execute(select(Book).where(Book.id.not_in(id_list)))

# IS NULL
result = await db.execute(select(Book).where(Book.description.is_(None)))

# IS NOT NULL
result = await db.execute(select(Book).where(Book.description.is_not(None)))
```

### 4.3 条件查询对比表

| 操作 | 异步写法（推荐） | 同步写法 |
|------|------------------|----------|
| 等于 | `Book.id == 1` | `Item.name == "手机"` |
| 不等于 | `Book.id != 1` | `Item.price != 0` |
| 大于 | `Book.price > 100` | `Item.price > 100` |
| 包含 | `Book.id.in_([1,2])` | `Item.name.in_(["手机","电脑"])` |
| 模糊 | `Book.name.like("%曹%")` | `Item.name.like("%手机%")` |
| AND | `and_(cond1, cond2)` | `and_(cond1, cond2)` |
| OR | `or_(cond1, cond2)` | `or_(cond1, cond2)` |
| NOT | `~Book.id.in_([1,2])` | `~Item.name.in_(["手机"])` |

### 4.4 聚合查询

```python
from sqlalchemy import func

@app.get("/book/count")
async def get_count(db: AsyncSession = Depends(get_database)):
    # count 计数
    result = await db.execute(select(func.count(Book.id)))
    count = result.scalar()
    
    # max 最大值
    result = await db.execute(select(func.max(Book.price)))
    max_price = result.scalar()
    
    # sum 求和
    result = await db.execute(select(func.sum(Book.price)))
    total_price = result.scalar()
    
    # avg 平均值
    result = await db.execute(select(func.avg(Book.price)))
    avg_price = result.scalar()
    
    # min 最小值
    result = await db.execute(select(func.min(Book.price)))
    min_price = result.scalar()
    
    return {
        "count": count,
        "max_price": max_price,
        "total_price": total_price,
        "avg_price": avg_price,
        "min_price": min_price
    }
```

### 4.5 GROUP BY 分组查询

```python
# GROUP BY 分组
@app.get("/book/stats")
async def get_book_stats(db: AsyncSession = Depends(get_database)):
    stmt = select(
        Book.publisher,
        func.count(Book.id).label("book_count"),
        func.avg(Book.price).label("avg_price")
    ).group_by(Book.publisher)
    
    result = await db.execute(stmt)
    stats = result.all()
    return [{"publisher": s[0], "count": s[1], "avg_price": s[2]} for s in stats]

# HAVING 分组过滤
@app.get("/book/popular_publishers")
async def get_popular_publishers(db: AsyncSession = Depends(get_database)):
    stmt = select(
        Book.publisher,
        func.count(Book.id).label("book_count")
    ).group_by(Book.publisher).having(
        func.count(Book.id) > 5  # 只返回书籍数量大于5的出版社
    )
    
    result = await db.execute(stmt)
    return result.all()
```

**聚合函数汇总：**

| 函数 | 说明 | 示例 |
|------|------|------|
| `func.count()` | 计数 | `func.count(Book.id)` |
| `func.sum()` | 求和 | `func.sum(Book.price)` |
| `func.avg()` | 平均值 | `func.avg(Book.price)` |
| `func.max()` | 最大值 | `func.max(Book.price)` |
| `func.min()` | 最小值 | `func.min(Book.price)` |

### 4.6 分页查询

```python
@app.get("/book/get_book_list")
async def get_book_list(
    page: int = 1,
    page_size: int = 3,
    db: AsyncSession = Depends(get_database)
):
    # 计算跳过的记录数
    skip = (page - 1) * page_size
    
    # offset 跳过的记录数，limit 每页的记录数
    stmt = select(Book).offset(skip).limit(page_size)
    result = await db.execute(stmt)
    books = result.scalars().all()
    return books
```

### 4.7 新增数据

```python
from pydantic import BaseModel

class BookBase(BaseModel):
    id: int
    bookname: str
    author: str
    price: float
    publisher: str

@app.post("/book/add_book")
async def add_book(book: BookBase, db: AsyncSession = Depends(get_database)):
    # 创建 ORM 对象
    book_obj = Book(**book.__dict__)
    db.add(book_obj)
    await db.commit()
    # refresh 获取生成的 ID
    await db.refresh(book_obj)
    return book_obj

# 批量新增
@app.post("/book/batch_add")
async def batch_add_books(books: list[BookBase], db: AsyncSession = Depends(get_database)):
    book_objs = [Book(**book.__dict__) for book in books]
    db.add_all(book_objs)
    await db.commit()
    return {"msg": f"成功添加 {len(books)} 本书籍"}
```

### 4.8 更新数据

```python
from pydantic import BaseModel

class BookUpdate(BaseModel):
    bookname: str
    author: str
    price: float
    publisher: str

@app.put("/book/update_book/{book_id}")
async def update_book(book_id: int, data: BookUpdate, db: AsyncSession = Depends(get_database)):
    # 1. 查找图书
    db_book = await db.get(Book, book_id)
    
    if db_book is None:
        raise HTTPException(status_code=404, detail="查无此书")
    
    # 2. 修改属性
    db_book.bookname = data.bookname
    db_book.author = data.author
    db_book.price = data.price
    db_book.publisher = data.publisher
    
    # 3. 提交到数据库
    await db.commit()
    await db.refresh(db_book)
    return db_book
```

### 4.9 删除数据

```python
@app.delete("/book/delete_book/{book_id}")
async def delete_book(book_id: int, db: AsyncSession = Depends(get_database)):
    # 先查再删
    db_book = await db.get(Book, book_id)
    
    if db_book is None:
        raise HTTPException(status_code=404, detail="查无此书")
    
    await db.delete(db_book)
    await db.commit()
    return {"msg": "删除图书成功"}
```

> **补充：实际项目中的软删除（Soft Delete）**
> 
> 在实际的商业项目中，通常不建议直接使用物理删除（如上文的 `db.delete`），而是采用**软删除**。
> - **核心概念**：逻辑上标记为已删除，但数据库中仍保留记录（通常通过 `is_deleted` 字段或 `deleted_at` 时间戳实现）。
> - **优势**：防止误删、保持统计报表一致性、满足审计要求。
> - **ORM 实现示例**：
> ```python
> # 假设模型中定义了 is_deleted: Mapped[bool] = mapped_column(default=False)
> async def soft_delete_book(book_id: int, db: AsyncSession = Depends(get_database)):
>     book = await db.get(Book, book_id)
>     if not book:
>         raise HTTPException(status_code=404, detail="未找到")
>     book.is_deleted = True # 仅修改状态，不调用 db.delete
>     await db.commit()
>     return {"msg": "已标记删除"}
> ```

### 4.10 ORM 操作总结

```python
# 基本查询
result = await db.execute(select(Model))           # 获取所有
result.scalars().all()

await db.get(Model, id)                            # 根据主键获取

# 条件过滤
select(Model).where(Model.field == value)
select(Model).where(Model.field > 100)

# 排序
select(Model).order_by(Model.field)                # 升序
select(Model).order_by(Model.field.desc())         # 降序

# 分页
select(Model).offset(skip).limit(limit)

# 聚合
select(func.count(Model.id))
select(func.sum(Model.field))
select(func.avg(Model.field))
```

### 4.11 ORM 使用注意事项

| 注意事项 | 说明 |
|----------|------|
| ✅ 提交事务 | 增删改操作后必须调用 `commit()` 提交事务 |
| ✅ 刷新对象 | 新增/更新后使用 `refresh()` 获取最新数据 |
| ✅ 关闭会话 | 使用 `finally` 确保会话被关闭 |
| ✅ 防止 SQL 注入 | 使用 ORM 参数化查询，避免字符串拼接 |
| ✅ 批量操作 | 大量数据使用 `add_all()` 提高性能 |
| ✅ 异常处理 | 使用 `try/except` 捕获异常并回滚 |
| ✅ 连接池配置 | 合理设置 `pool_size` 和 `max_overflow` |
