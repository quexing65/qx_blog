# 02. FastAPI 路由与请求

## 1. FastAPI 简介

FastAPI 是一个现代、快速（高性能）的 Python Web API 框架，具有以下特点：

- ⚡ **高性能**：基于 Starlette 和 Pydantic，性能与 Node.js 和 Go 相当
- 🚀 **开发效率**：自动生成 API 文档（Swagger UI 和 ReDoc）
- 🔒 **类型安全**：基于 Python 类型提示，自动数据验证
- 📦 **异步支持**：原生支持 async/await 异步编程

### 快速开始

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"message": "Hello World"}
```

启动服务：
```bash
uvicorn main:app --reload
```

访问文档：
- Swagger UI：`http://127.0.0.1:8000/docs`
- ReDoc：`http://127.0.0.1:8000/redoc`

## 2. HTTP 请求流程

```
客户端请求 → FastAPI 路由匹配 → 参数解析 → 业务处理 → 返回响应 → 客户端接收
```

**详细流程：**
1. **客户端请求**：发送 HTTP 请求（GET/POST/PUT/DELETE）
2. **路由匹配**：FastAPI 根据 URL 和方法匹配对应的路由函数
3. **参数解析**：自动解析路径参数、查询参数、请求体
4. **数据验证**：使用 Pydantic 模型验证参数
5. **业务处理**：执行路由函数中的逻辑
6. **返回响应**：将结果序列化为 JSON（或其他格式）
7. **客户端接收**：解析响应数据

常见 HTTP 请求方法如下：

| 方法          | 方法      | 作用          | 常见场景         |
| ----------- | ------- | ----------- | ------------ |
| **GET**     | get     | 获取资源        | 查询数据         |
| **POST**    | post    | 创建资源 / 提交数据 | 注册用户、登录、上传文件 |
| **PUT**     | put     | 整体更新资源      | 修改完整用户信息     |
| **PATCH**   | patch   | 部分更新资源      | 修改用户名、头像     |
| **DELETE**  | delete  | 删除资源        | 删除用户、删除文章    |
| **HEAD**    | head    | 获取响应头       | 检查资源是否存在     |
| **OPTIONS** | options | 查询服务器支持的方法  | 跨域预检         |
| **TRACE**   | trace   | 测试请求链路      | 调试，很少用       |
| **CONNECT** | connect | 建立代理隧道      | HTTPS 代理     |

### 1. GET：获取数据

意思：

> 我要从服务器拿东西

例如：
请求：
```
GET /users/100
```
服务器：
```
{
    "id":100,
    "name":"张三"
}
```
FastAPI：
```
@app.get("/users/{id}")
def get_user(id:int):
    return {"id":id}
```
特点：
- 参数通常放 URL
- 不应该修改服务器数据
- 可以缓存
- 浏览器访问网页本质就是 GET
例如：
```
https://www.baidu.com/search?q=python
```
这里：
```
q=python
```
就是 GET 参数。

---

### 2. POST：提交数据 / 创建

意思：

> 我要给服务器发送一些数据，让服务器处理

比如注册：
请求：
```
POST /users
```
Body：
```
{
    "username":"xiaoming",
    "password":"123456"
}
```
服务器：
创建用户：
```
id=1
username=xiaoming
```
FastAPI：
```
@app.post("/users")
def create_user(user:User):
    return user
```
常见：
- 注册
- 登录
- 上传文件
- 创建订单
- 提交表单
例如：
登录：
```
POST /login
```
提交：
```
{
 "username":"admin",
 "password":"123"
}
```

返回：

```
{
 "token":"xxxxx"
}
```

---

### 3. PUT：完整更新

意思：

> 用新的数据替换旧数据

原数据：
```
{
"id":1,
"name":"张三",
"age":20
}
```
PUT：
```
PUT /users/1
```
提交：
```
{
"name":"李四",
"age":25
}
```
结果：
```
{
"id":1,
"name":"李四",
"age":25
}
```

特点：

需要提交完整对象。

---

### 4. PATCH：部分修改

意思：

> 我只改其中几个字段

例如：
只改名字：
```
PATCH /users/1
```
提交：
```
{
"name":"王五"
}
```
结果：
```
{
"id":1,
"name":"王五",
"age":20
}
```
不会影响 age。

---

PUT 和 PATCH 区别：

假设用户：

```
{
"name":"张三",
"age":18,
"sex":"男"
}
```

#### PUT

发送：
```
{
"name":"李四"
}
```
可能变成：
```
{
"name":"李四"
}
```
其他字段丢失。

---

#### PATCH
发送：
```
{
"name":"李四"
}
```
结果：
```
{
"name":"李四",
"age":18,
"sex":"男"
}
```

---

### 5. DELETE：删除

意思：

> 删除服务器资源

例如：
```
DELETE /users/100
```
删除：
```
id=100 的用户
```
FastAPI：
```
@app.delete("/users/{id}")
def delete_user(id:int):
    return {
        "msg":"deleted"
    }
```

---

### 6. HEAD

类似 GET：
但是：
只返回响应头，不返回正文。
例如：
检查文件大小：
```
HEAD /video.mp4
```
返回：
```
Content-Length: 500MB
```
不会真的下载视频。

---

### 7. OPTIONS

询问：

> 服务器支持哪些请求方式？

例如：
```
OPTIONS /users
```
返回：
```
Allow:
GET
POST
DELETE
```
常用于：
#### CORS跨域
浏览器发送：
```
OPTIONS
```
询问：
"我能不能跨域访问？"

---

### 8. TRACE
调试用途。
例如：
查看请求经过哪些代理。
现在基本不用。

---

### 9. CONNECT

建立代理连接。
例如：
浏览器访问 HTTPS：

```
CONNECT google.com:443
```

告诉代理：
"帮我建立一个 TCP 隧道"
普通开发基本不会直接使用。


## 3. 路由基础

### 基本路由

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"message": "Hello World"}

@app.get("/hello")
async def get_hello():
    return {"msg": "你好 FastAPI"}
```

### 路由参数（Path Parameters）

```python
from fastapi import FastAPI, Path

app = FastAPI()

@app.get("/book/{id}")
async def get_book(id: int = Path(..., gt=0, lt=101, description="书籍id，取值范围1-100")):
    return {"id": id, "title": f"这是第{id}本书"}

@app.get("/author/{name}")
async def get_name(name: str = Path(..., min_length=2, max_length=10)):
    return {"msg": f"这是{name}的信息"}
```

**Path 参数验证选项：**

| 参数 | 说明 |
|------|------|
| `gt` | 大于 (greater than) |
| `ge` | 大于等于 (greater than or equal) |
| `lt` | 小于 (less than) |
| `le` | 小于等于 (less than or equal) |
| `min_length` | 最小长度 |
| `max_length` | 最大长度 |
| `description` | 参数描述 |

## 3. 查询参数（Query Parameters）

```python
from fastapi import FastAPI, Query

app = FastAPI()

@app.get("/news/news_list")
async def get_news_list(
    skip: int = Query(0, description="跳过的记录数", lt=100),
    limit: int = Query(10, description="返回的记录数")
):
    return {"skip": skip, "limit": limit}
```

**Query 参数特点：**
- 定义在函数参数中，不是路径的一部分
- 可以设置默认值
- 支持数据验证（`gt`, `lt`, `ge`, `le`, `min_length`, `max_length`）
- 访问方式：`/news/news_list?skip=0&limit=10`

## 4. 请求体参数（Request Body）

### 使用 Pydantic 模型

```python
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI()

class User(BaseModel):
    username: str = Field(default="张三", min_length=2, max_length=10, description="用户名，长度要求2-10个字")
    password: str = Field(min_length=3, max_length=20)

@app.post("/register")
async def register(user: User):
    return user
```

**Field 验证选项：**

| 参数                        | 说明                                     |
| ------------------------- | -------------------------------------- |
| 无默认值 / `...`           | **必填字段**；Pydantic v2 通常直接省略默认值即可             |
| `default`                 | 默认值，不传则使用该值（如 `None` 表示可选）             |
| `min_length`              | 最小长度（字符串）                              |
| `max_length`              | 最大长度（字符串）                              |
| `gt` / `ge` / `lt` / `le` | 数值范围验证（gt=大于, ge=大于等于, lt=小于, le=小于等于） |
| `description`             | 字段描述（显示在 API 文档中）                      |
| `title`                   | 字段标题                                   |
| `examples`                | 示例值列表                                  |

### 使用 Pydantic v2 配置示例

```python
from fastapi import FastAPI
from pydantic import BaseModel, ConfigDict, Field

app = FastAPI()

class Item(BaseModel):
    model_config = ConfigDict(
        json_schema_extra={
            "example": {
                "name": "商品名称",
                "description": "商品描述",
                "price": 99.99,
                "tax": 10.0,
            }
        }
    )

    name: str = Field(min_length=1, max_length=50)
    description: str | None = Field(default=None, max_length=300)
    price: float = Field(gt=0, description="价格必须大于 0")
    tax: float | None = Field(default=None, ge=0)

@app.post("/items/")
def create_item(item: Item):
    return item
```

**`model_config.json_schema_extra` 的作用：**
- 在 Swagger UI 中显示示例数据
- 帮助前端开发人员理解请求格式
- 自动生成 API 文档的示例

## 5. 响应类型

### 5.1 JSON 响应（默认）

```python
@app.get("/")
async def root():
    return {"message": "Hello World"}
```

### 5.2 HTML 响应

```python
from fastapi import FastAPI
from fastapi.responses import HTMLResponse

app = FastAPI()

@app.get("/html", response_class=HTMLResponse)
async def get_html():
    return "<h1>这是一级标题</h1>"
```

### 5.3 文件响应

```python
from fastapi import FastAPI
from fastapi.responses import FileResponse

app = FastAPI()

@app.get("/file")
async def get_file():
    path = "./files/1.jpeg"
    return FileResponse(path)
```

### 5.4 其他响应类型

| 响应类型                | 用途                       |
| ------------------- | ------------------------ |
| `JSONResponse`      | 返回 JSON 数据（默认）           |
| `HTMLResponse`      | 返回 HTML 内容               |
| `PlainTextResponse` | 返回纯文本                    |
| `FileResponse`      | 返回文件（PDF、Excel 等）        |
| `StreamingResponse` | 流式响应（文件下载）               |
| `RedirectResponse`  | 重定向响应                    |
| `ORJSONResponse`    | 高性能 JSON 响应（基于 orjson 库） |

### 5.5 自定义响应类

```python
from fastapi import FastAPI, Response
from fastapi.responses import JSONResponse

app = FastAPI()

class CustomResponse(JSONResponse):
    def render(self, content):
        # 自定义响应头
        self.headers["X-Custom-Header"] = "CustomValue"
        return super().render(content)

@app.get("/custom", response_class=CustomResponse)
def get_custom():
    return {"message": "Custom Response"}
```

**使用场景：**
- 添加自定义响应头
- 统一响应格式
- 特殊的数据序列化逻辑

### 5.6 FileResponse 详细参数

```python
from fastapi import FastAPI
from fastapi.responses import FileResponse

app = FastAPI()

@app.get("/download")
async def download_file():
    return FileResponse(
        path="file.pdf",
        filename="download.pdf",      # 下载时的文件名
        media_type="application/pdf"  # MIME 类型
    )
```

**常用 MIME 类型：**

| 文件类型 | MIME 类型 |
|----------|-----------|
| PDF | `application/pdf` |
| Excel | `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` |
| Word | `application/vnd.openxmlformats-officedocument.wordprocessingml.document` |
| 图片 | `image/jpeg`, `image/png` |
| ZIP | `application/zip` |

## 6. 响应模型（Response Model）

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class News(BaseModel):
    id: int
    title: str
    content: str

@app.get("/news/{id}", response_model=News)
async def get_news(id: int):
    return {
        "id": id,
        "title": f"这是第{id}本书",
        "content": "这是一本好书"
    }
```

**response_model 的作用：**
- 自动过滤响应数据，只返回模型定义的字段
- 自动生成 API 文档
- 自动数据验证

## 7. 异常处理

### 7.1 HTTPException 基础用法

```python
from fastapi import FastAPI, HTTPException

app = FastAPI()

items = {"foo": "The Foo Wrestlers"}

@app.get("/items/{item_id}")
def read_item(item_id: str):
    if item_id not in items:
        raise HTTPException(
            status_code=404,
            detail="Item not found",
            headers={"X-Error": "There goes my error"}  # 可选：自定义响应头
        )
    return {"item": items[item_id]}
```

**HTTPException 参数：**
- `status_code`：HTTP 状态码（400, 401, 403, 404, 500 等）
- `detail`：错误详情信息
- `headers`：可选，自定义响应头

### 7.2 自定义异常处理器

```python
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse

app = FastAPI()

# 自定义异常类
class UnicornException(Exception):
    def __init__(self, name: str):
        self.name = name

# 注册异常处理器
@app.exception_handler(UnicornException)
async def unicorn_exception_handler(request: Request, exc: UnicornException):
    return JSONResponse(
        status_code=418,
        content={"message": f"Oops! {exc.name} did something. There goes a rainbow..."}
    )

@app.get("/unicorns/{name}")
def read_unicorn(name: str):
    if name == "yolo":
        raise UnicornException(name=name)
    return {"unicorn_name": name}
```

**自定义异常的优势：**
- 统一错误响应格式
- 集中管理业务异常
- 更好的错误追踪和日志记录

### 7.3 常见 HTTP 状态码

| 状态码 | 含义 | 使用场景 |
|--------|------|----------|
| 200 | OK | 请求成功 |
| 201 | Created | 资源创建成功 |
| 400 | Bad Request | 请求参数错误 |
| 401 | Unauthorized | 未认证（未登录） |
| 403 | Forbidden | 无权限访问 |
| 404 | Not Found | 资源不存在 |
| 422 | Unprocessable Entity | 数据验证失败 |
| 500 | Internal Server Error | 服务器内部错误 |
